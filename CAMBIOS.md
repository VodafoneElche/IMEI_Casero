# Cambios

Cada apartado `## X.Y.Z` se usa como nota de la versión publicada en GitHub.

## 1.2.0

- Reescrita en C nativo para Windows: arranca al instante y el instalador pasa de 107 MB a menos de 2 MB.
- Se actualiza sola: al arrancar comprueba si hay una versión nueva en GitHub y la instala con un clic.
- Quitado el botón «Buscar ficha oficial con IA» (y la clave de la API en Ajustes).
- iUnlocker se abre en el navegador con el IMEI ya copiado; el resultado se marca con los botones de «Buscar mi iPhone».
- Al instalarla se desinstala la versión anterior. El historial y el logo se conservan.
- Nuevo: `ComprobadorIMEI.exe --imei 351091214899373` abre la app comprobando ese IMEI.
